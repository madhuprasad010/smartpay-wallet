# SmartPay — Render.com Hosting & Deployment Guide

This guide details how to deploy the entire SmartPay FinTech platform onto **[Render.com](https://render.com)** using Render Blueprints (`render.yaml`).

## 2. Prerequisites for Cloud Deployment

Before launching the Render Blueprint:

1. **GitHub Repository**: Push this monorepo to your GitHub account:
   ```bash
   git remote add origin https://github.com/<your-username>/smartpay-wallet.git
   git branch -M main
   git push -u origin main
   ```
2. **Cloud MySQL Database**:
   Render provides managed PostgreSQL. Since SmartPay microservices use MySQL 8.4 with Flyway migrations, obtain a free or starter MySQL connection string from:
   * **[Aiven for MySQL](https://aiven.io)** (Free tier available)
   * **[PlanetScale](https://planetscale.com)**
   * **[Railway](https://railway.app)** or **AWS RDS MySQL**
3. **Cloud Kafka & RabbitMQ (Optional for event streaming)**:
   * **Kafka**: **[Upstash Kafka](https://upstash.com/docs/kafka/overall/getstarted)** (Free serverless Kafka) or Confluent Cloud.
   * **RabbitMQ**: **[CloudAMQP](https://www.cloudamqp.com)** (Free Lemur plan).

## 3. One-Click Deploy via Render Blueprint

1. Log in to your **[Render Dashboard](https://dashboard.render.com)**.
2. Click **New +** in the top-right corner and select **Blueprint**.
3. Connect your GitHub repository (`smartpay-wallet`).
4. Render automatically detects the root `render.yaml` specification:
   * **Frontend (`smartpay-web`)**: Deployed as a high-speed Static Site served across Render's global CDN.
   * **API Gateway (`smartpay-api-gateway`)**: Deployed as a public Web Service exposing `/api/v1/*`.
   * **8 Microservices**: Deployed as **Private Services (`pserv`)** accessible strictly within Render's secure internal private network.
   * **Redis Cache (`smartpay-redis`)**: Provisioned as a Render Managed Redis instance.
5. In the Blueprint configuration screen, input your environment variables (or let Render generate secure random keys):
   * `MYSQL_HOST`, `MYSQL_PORT`, `MYSQL_USER`, `MYSQL_PASSWORD`
   * `JWT_SECRET` (auto-generated by Render)
   * `KAFKA_BOOTSTRAP_SERVERS` (e.g. from Upstash or internal broker)
6. Click **Apply**. Render will trigger parallel Docker builds and deploy the entire fleet.

## 4. Alternative: Single-Instance Hosting on Render

If you prefer to host the entire stack (all 9 microservices + frontend + infra) on a **single low-cost instance** without managing multiple private services:

1. Render supports running Docker Compose or multi-container stacks via a single Web Service with persistent disks.
2. In your Render dashboard, choose **New Web Service** → **Deploy an existing image** or **Build from Dockerfile**.
3. Map Port `80` (Nginx reverse proxy), which routes both the frontend UI and the backend API Gateway transparently.

## 5. Environment Variables Configuration

| Variable | Description | Example / Recommended Value |
|---|---|---|
| `SPRING_PROFILES_ACTIVE` | Active Spring profile | `docker` or `prod` |
| `JAVA_TOOL_OPTIONS` | JVM memory tuning | `-Xms128m -Xmx384m -XX:+UseSerialGC` |
| `JWT_SECRET` | 384-bit HMAC secret | Render auto-generated base64 secret |
| `MYSQL_HOST` | Hostname of MySQL database | `mysql.aivencloud.com` |
| `MYSQL_PORT` | Port of MySQL database | `3306` (or Aiven port) |
| `REDIS_HOST` | Hostname of Redis | Render auto-links from `smartpay-redis` |
| `KAFKA_BOOTSTRAP_SERVERS` | Kafka brokers | `your-cluster.upstash.io:9092` |
| `VITE_API_BASE_URL` | Public API URL for frontend | `https://smartpay-api-gateway.onrender.com/api/v1` |

## 6. Post-Deployment Verification

Once Render finishes deploying:

1. **Verify API Gateway Health:**
   ```bash
   curl -i https://<your-gateway-subdomain>.onrender.com/actuator/health
   ```
   *Expected Response:* `{"status": "UP"}`

2. **Verify Frontend Application:**
   Open `https://<your-web-subdomain>.onrender.com` in your web browser. You will see the SmartPay landing and login pages.

3. **Verify Auth & Wallet Creation:**
   Register a user and log in to verify token generation, wallet creation, and live dashboard rendering.
